흐름 1

ALyraHUD BeginPlay 에서 AddWidgets 호출 흐름

HUD 가 spawn 되고 NAME_GameActorReady 가 발송되어 AddWidgets 가 위젯을 주입하는 인과.

  1. ALyraHUD spawn검증State

    PlayerController 가 HUD 클래스 인스턴스 생성.

  2. ↓

    PreInitializeComponents 에서 AddGameFrameworkComponentReceiver(this).

  3. BeginPlay검증State

    NAME_GameActorReady 이벤트 발송.

  4. ↓
  5. UGameFeatureAction_AddWidgets::HandleActorExtension검증State

    extension handler 가 NAME_GameActorReady 를 받아 AddWidgets 호출.

  6. ↓
  7. Layer push + Slot register검증State

    Layout[] 의 entry 마다 layer push, Widgets[] 의 entry 마다 slot register.

참조

UI.Layer 4 종

Config/DefaultGameplayTags.ini 에 등록된 4 layer. z-order 와 input priority 가 layer 순서로 결정.

Layer 태그z-order전형적 콘텐츠
UI.Layer.Game가장 아래HUD layout (in-game)
UI.Layer.GameMenu중간game menu (inventory, scoreboard)
UI.Layer.Menu위escape menu, settings
UI.Layer.Modal가장 위controller disconnect, error dialog
결정

bShowHUD 동기화 규칙

ULyraUIManagerSubsystem::SyncRootLayoutVisibilityToShowHUD 가 AHUD::bShowHUD 와 root layout 가시성을 양방향 동기화.

  1. 1. bShowHUD == true

    root layout visible. 일반 게임 상태.

  2. 2. bShowHUD == false

    root layout collapsed. 콘솔 명령 ShowHUD 또는 cinematic 진입 시.

  3. 3. 동기화 시점

    매 frame 또는 변경 이벤트 시. AHUD 측 toggle 과 UI subsystem 측 toggle 이 일치 유지.
