경로보유 actor용도
PlayerState ASCALyraPlayerState일반 플레이어 어빌리티 (가장 흔함). owner = PS, avatar = Pawn.
GameState ASCALyraGameStateGamePhase 어빌리티 owner. avatar 도 GS.

흐름 1

PawnExtensionComponent 초기화 흐름

PlayerState ASC + Pawn avatar 연결. InitState 4 단계가 순차 진행.

  1. InitState_Spawned검증State

    Pawn spawn 직후. PawnExtensionComponent 생성.

  2. ↓
  3. InitState_DataAvailable검증State

    PawnData 와 PlayerState 가 모두 준비됨.

  4. ↓
  5. InitState_DataInitialized검증State

    InitializeAbilitySystem 호출. ULyraAbilitySystemComponent::InitAbilityActorInfo(PS, Pawn) 실행.

  6. ↓

    bHasNewPawnAvatar 분기.

  7. AbilitySet grant + AnimInstance 연결검증State

    PawnData->AbilitySets[] 일괄 grant. ULyraAnimInstance::InitializeWithAbilitySystem 호출.

  8. ↓
  9. InitState_GameplayReady검증State

    최종 상태. TryActivateAbilitiesOnSpawn 으로 OnSpawn ability 활성.

결정

pawn 교체 시 avatar 만 갱신

새 pawn 으로 possess 될 때 ASC 와 어빌리티가 그대로 유지되는 이유.

  1. 1. ASC 는 PlayerState 소유

    PS 가 player session 수명. pawn 교체와 무관하게 유지.

  2. 2. InitAbilityActorInfo 재호출

    새 pawn 으로 InitAbilityActorInfo(PS, NewPawn) 호출. owner 는 그대로 PS, avatar 만 새 pawn.

  3. 3. bHasNewPawnAvatar = true 분기

    새 avatar 감지 시 OnPawnAvatarSet 디스패치, 어빌리티 연결 재설정.

  4. 4. 어빌리티 spec 은 ASC 보유

    spec 은 PS 의 ASC 에 남아 있음. 새 pawn 에서 같은 어빌리티 사용 가능.
