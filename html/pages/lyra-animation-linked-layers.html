참조

ALI_ItemAnimLayers 14 함수 인터페이스

ALI_ItemAnimLayers 는 base ABP 가 무기별 layer 에게 호출하는 14 개 함수의 시그니처를 정의. state 별로 layer 가 자기 무기에 맞는 pose 를 제공.

함수대응 base state역할
FullBody_IdleStateLocomotionSM Idle정지 시 무기별 idle pose.
FullBody_StartStateLocomotionSM Start정지 에서 이동 전환 무기별 pose.
FullBody_CycleStateLocomotionSM Cycle이동 사이클 무기별 pose (jog 또는 walk).
FullBody_StopStateLocomotionSM Stop정지 시퀀스 무기별 pose.
FullBody_PivotStateLocomotionSM Pivot방향 전환 무기별 pose.
FullBody_JumpStartStateLocomotionSM JumpStart점프 시작 무기별 pose.
FullBody_JumpApexStateLocomotionSM JumpApex점프 정점 무기별 pose.
FullBody_FallLoopStateLocomotionSM FallLoop낙하 루프 무기별 pose.
FullBody_FallLandStateLocomotionSM FallLand착지 무기별 pose.
FullBody_Aimingbase AnimGraph slotaim offset 과 ADS 합성.
FullBodyAdditivesbase AnimGraph slot추가 additive 합성.
FullBody_SkeletalControlsbase AnimGraph slotskeletal control (사격 자세, 손가락).
LeftHandPose_OverrideStatebase AnimGraph slot왼손 grip pose override.
UpdateBlendWeightData 등 보조linked layer ThreadSafe매 frame blend weight 갱신 (1 함수가 14 카운트 중 1).
구조

상속 관계 (base 에서 child layer)

모든 무기 layer 는 공통 ABP_ItemAnimLayersBase 를 상속. Shotgun 만 Rifle layer 를 부모로 가짐 (변형 layer).

ABP_ItemAnimLayersBase

공통 부모. 14 인터페이스 함수의 기본 구현, ThreadSafe Update 골격, blend weight 데이터.

  • implements ALI_ItemAnimLayers

ABP_UnarmedAnimLayers

맨손. Unarmed locomotion set 사용.

  • 109 시퀀스 (Locomotion/Unarmed)

ABP_PistolAnimLayers

권총. Pistol locomotion set.

  • 107 시퀀스 (Locomotion/Pistol)

ABP_RifleAnimLayers

소총. Rifle locomotion set. 가장 큰 세트로 기준 역할.

  • 118 시퀀스 (Locomotion/Rifle)

ABP_ShotgunAnimLayers

샷건. ABP_RifleAnimLayers 를 부모로 갖는 변형. 일부 sequence 만 override.

  • 5 시퀀스 (Locomotion/Shotgun override)

흐름 1

런타임 layer 교체 흐름

무기 변경 시 base ABP 의 LinkedAnimLayer node 가 새 layer class 로 교체되고 다음 frame 부터 새 sequence set 을 사용.

  1. 무기 장착 이벤트검증State

    ULyraWeaponInstance 의 EquippedAnimSet 이 새 무기로 결정.

  2. ↓

    SelectBestLayer 호출 (선택 규칙 페이지 참조).

  3. SelectBestLayer 결과 → LinkAnimClassLayers검증State

    base ABP 의 LinkedAnimLayer node 가 LinkAnimClassLayers API 로 layer class 교체.

  4. ↓
  5. 다음 frame 에 새 layer 가 ALI 14 함수 호출에 응답검증State

    base 의 state 마다 새 layer 의 FullBody_*State 함수가 새 sequence 를 출력.
