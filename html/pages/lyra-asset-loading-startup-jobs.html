참조

STARTUP_JOB 매크로 2 종

라이라 AssetManager 가 정의하는 매크로. 람다 캡처와 weight 부여.

매크로weight역할
STARTUP_JOB(JobFunc)1.f (default)일반 가벼운 작업
STARTUP_JOB_WEIGHTED(JobFunc, JobWeight)지정값무거운 작업 (예: GameData 로드 25.f)
구현: 매크로는 람다로 JobFunc 를 캡처해 FLyraAssetManagerStartupJob USTRUCT 로 큐에 등록.

DoAllStartupJobs 실행 흐름

큐에 등록된 작업이 순차 실행되며 진행률을 누적 보고.

  1. StartupJobs[] 순회검증State

    등록된 job 을 index 순서로 실행.

  2. ↓
  3. Job::DoJob 호출검증State

    람다 실행. async load 시 FStreamableHandle 반환.

  4. ↓

    handle 이 있으면 WaitUntilComplete(0.0f, false) 로 폴링.

  5. SubstepProgressDelegate broadcast검증State

    60Hz throttle 로 진행률 broadcast. UI 가 progress bar 갱신.

  6. ↓
  7. 완료 시 누적 progress 갱신검증State

    완료된 job 의 weight 만큼 progress 증가. 다음 job 진행.

결정

진행률 가중치 결정

job 별 weight 를 어떻게 정할지.

  1. 1. 가벼운 자산 인덱싱

    weight = 1.f. STARTUP_JOB 매크로의 default.

  2. 2. 무거운 자산 비동기 로드

    weight = 측정된 비례값 (예: GameData 25.f). 진행률 bar 가 단계 별로 멈추지 않게.

  3. 3. Dedicated server 분기

    IsRunningDedicatedServer() 검사. server 에는 UI 자산 로드 생략 가능.

  4. 4. UpdateInitialGameContentLoadPercent 후크

    커스텀 UI 가 진행률에 연결. 라이라는 비워둠, 사용자 채움.
