흐름 1

부팅에서 Experience 활성화 흐름

엔진 부팅부터 Experience Action 실행까지의 인과.

  1. 엔진 부팅검증State

    AssetManagerClassName ini 설정에 따라 ULyraAssetManager 생성.

  2. ↓

    StartInitialLoading 호출.

  3. StartupJob 큐 실행검증State

    STARTUP_JOB 매크로로 등록된 작업이 순차 실행. 진행률 누적.

  4. ↓

    자산 인덱싱 + GameData 로드.

  5. GameMode 가 Experience 결정검증State

    URL 옵션 또는 default 로 Experience 선택.

  6. ↓
  7. Bundle 비동기 로드검증State

    Client / Server bundle 분기 로드.

  8. ↓
  9. GameFeature 활성화검증State

    NumGameFeaturePluginsLoading 카운트다운 후 Action 실행 (AddWidgets / AddComponents / ...).

시스템 페이지 경로

3 층을 깊이 학습하는 페이지들.

  • assetmanager-bootstrap: UAssetManager 파생과 ini 등록.
  • startup-jobs: STARTUP_JOB 매크로와 진행률 가중치.
  • gamedata: ULyraGameData 전역 자산 패턴.
  • primary-asset-types: 8 종 Primary Asset Type.
  • experience-state-machine: 7 단계 state machine.
  • asset-bundles: AssetBundle 메타 9 곳.
  • bp-async-loading-screen: AsyncAction_ExperienceReady + Loading Screen.
  • porting-guide: 다른 프로젝트로 이식 (옵션 A / B / C).
