구조

보정 스택 5 계층

final pose 근처에서 작동하는 보정 단계. 위에서 아래로 평가.

1Distance Matching

start / stop / pivot / jump 시퀀스의 play position 을 distance curve 와 매칭. 발 미끄러짐 방지.

  • LocomotionDistanceCurveName
  • JumpDistanceCurveName

2Stride Warping

cycle 의 stride 를 실제 속도에 맞춰 root bone 회전과 leg IK 로 조절. cycle play rate 보조.

  • stride warping alpha

3Turn In Place / Root Yaw

controller yaw 가 actor yaw 와 다를 때 root bone 회전. RootYawOffset + TurnYawCurveValue.

  • RootYawOffsetMode

4Hand IK / Foot IK (Control Rig)

weapon space 가상 본 (VB IK_Hand_L_weaponSpace) 기준으로 손 위치 보정. foot placement 도 Control Rig 노드.

  • FullBody_SkeletalControls
  • LeftHandPose_OverrideState

5Post Process + Retarget

mesh 별 final-pose 후처리 (ABP_Manny_PostProcess, ABP_Quinn_PostProcess). UE4 mannequin 호환은 ABP_Mannequin_Retarget.

  • mesh 마다 1 회 평가

흐름 1

Distance Matching 으로 stop 정렬 흐름

Cycle 에서 입력이 끊겼을 때 stop 시퀀스가 정확한 위치에서 끝나도록 play position 을 매 frame 조절.

  1. Cycle → Stop 전이검증State

    ShouldDistanceMatchStop 평가, true 면 distance matching 활성.

  2. ↓

    GetPredictedStopDistance 로 남은 거리 계산.

  3. stop 시퀀스의 distance curve 와 매칭검증State

    sequence 의 LocomotionDistanceCurveName curve 와 남은 거리 비교, 매칭되는 play position 으로 jump.

  4. ↓
  5. 매 frame play position 갱신검증State

    남은 거리가 줄어드는 만큼 play position 도 앞으로. 시퀀스 끝에 도달할 때 캐릭터가 정확히 멈춤.

결정

IK / Control Rig 활성 조건

hand IK, foot placement, Control Rig 가 켜지는 분기.

  1. 1. hand IK alpha

    UpdateSkelControlData 에서 무기 종류와 ADS 상태에 따라 alpha 결정. 무기 없는 idle 에는 alpha 0.

  2. 2. foot placement

    ShouldEnableFootPlacement 가 true 일 때만. 일반적으로 idle / cycle 에서 켜지고 jump / fall 에서 꺼짐.

  3. 3. Control Rig

    ShouldEnableControlRig 가 true 일 때만. mesh 가 Control Rig 자산을 갖고 있어야 함.

  4. 4. Post Process ABP

    mesh 의 PostProcessAnimBlueprint 슬롯에 ABP 가 설정돼 있으면 자동 활성. main ABP 의 출력 pose 위에 한 번 더 평가.
