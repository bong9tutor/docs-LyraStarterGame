CommonUI 를 새 프로젝트에 활성화하는 5 단계 절차. 라이라도 같은 패턴.

단계설정 위치역할
1. viewport routingProject Settings, General, Game Viewport Client Class = CommonGameViewportClient입력을 CommonUI 로 라우팅
2. input action data tableCommon Input Settings 의 Input Data액션 (Confirm / Cancel / ...) 정의
3. default navnavigation 설정focus 이동 규칙
4. controller dataCommonInputBaseControllerDataplatform 별 input 매핑
5. stylesCommonButtonStyle 등 style 자산위젯 외형 일괄 적용

UI.Action 입력 태그

CommonUI 입력 액션의 라이라 tag. 데이터 테이블이 키 / 버튼 매핑 보유.

태그역할대표 사용
UI.Action.Confirm확인 / 진행대화 박스, 선택
UI.Action.Cancel취소 / 닫기back, 메뉴 닫기
UI.Action.NextTab다음 탭설정 화면 탭 이동
UI.Action.PreviousTab이전 탭설정 화면 탭 이동
UI.Action.Escapeescape menu 호출ULyraHUDLayout 의 escape menu

Common Style 자산

위젯 외형을 자산으로 분리해 일괄 테마. 라이라 CDO 는 부분 검증.

  • CommonButtonStyle: 버튼의 normal / hovered / pressed / disabled state 별 brush + sound.
  • CommonTextStyle: 텍스트의 font / size / color / shadow.
  • CommonBorderStyle: 박스 / panel 의 background brush + padding.
활용: style 자산을 변경하면 그 자산을 참조하는 모든 위젯이 일괄 갱신. 디자인 시스템의 단일 출처.
