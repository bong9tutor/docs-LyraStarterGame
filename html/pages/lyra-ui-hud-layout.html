흐름 1

Escape 액션에서 게임 메뉴 push 흐름

UI.Action.Escape 액션이 ULyraHUDLayout 에서 binding 되어 게임 메뉴를 layer 에 push.

  1. RegisterUIActionBinding 등록검증State

    ULyraHUDLayout::NativeOnInitialized 에서 UI.Action.Escape 액션을 HandleEscapeAction 함수에 binding.

  2. ↓

    Escape 키 또는 game pad 의 매핑된 입력.

  3. HandleEscapeAction 호출검증State

    콜백이 실행.

  4. ↓
  5. PushStreamedContentToLayer_ForPlayer검증State

    UCommonUIExtensions::PushStreamedContentToLayer_ForPlayer(LocalPlayer, UI.Layer.Menu, EscapeMenuClass) 로 async load + push.

  6. ↓
  7. W_LyraGameMenu 표시검증State

    W_DefaultHUDLayout CDO 의 EscapeMenuClass = /Game/UI/Hud/W_LyraGameMenu.

흐름 2

컨트롤러 분리에서 modal 화면 흐름

platform device mapper delegate 가 분리 감지 후 modal 화면을 layer 에 push.

  1. IPlatformInputDeviceMapper delegate검증State

    컨트롤러 연결 / 페어링 변경 시 delegate 발생.

  2. ↓

    Platform.Trait.Input.PrimarlyController 검사. PC 에는 trait 없음 → 비활성.

  3. trait 매칭 시검증Decision

    콘솔 환경에서만 분리 화면 표시 로직 실행.

  4. ↓
  5. PushContentToLayer_ForPlayer검증State

    UI.Layer.Menu 에 W_DefaultHUDLayout CDO 의 /Game/UI/Foundation/Dialogs/W_ControllerDisconnected push.

참고: PC 에서 컨트롤러를 뽑아도 modal 이 안 뜨는 건 의도. Platform.Trait.Input.PrimarlyController trait 이 없기 때문.
