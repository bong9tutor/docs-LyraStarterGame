챕터 브리프

이 챕터의 질문

  • LocomotionSM 의 state 는 어떻게 전이되는가?
  • alias 와 conduit 은 왜 필요한가?
  • jump, fall, land 가 ground locomotion 과 어떻게 합류하는가?

먼저 알아둘 것

  • state 는 실제 pose 를 출력하는 노드. alias 는 여러 state 를 한 묶음으로 묶어 전이 조건을 단순화하는 별칭.
  • conduit 은 조건만 평가하는 분기 노드. pose 출력 없이 다른 state 로 분기.

선행 학습

  • Base ABP pose graph: LocomotionSM 출력 pose 가 어디로 들어가는지 알아야 본 페이지의 state 가 의미를 가진다.

흐름 1

Idle 에서 Start, Cycle

정지 상태에서 입력이 들어와 이동이 시작되고 사이클로 진입.

  1. Idle검증State

    정지 사이클 재생.

  2. ↓
    HasVelocityHasAcceleration

    속도 / 가속이 0 이상이고 입력이 들어옴.

  3. Start검증State

    정지 에서 이동 전환 시작 동작. Distance Matching 으로 발 미끄러짐 방지.

  4. ↓

    시작 시퀀스 완료 또는 속도 지속.

  5. Cycle검증State

    이동 사이클 (jog 또는 walk) 루프. 속도에 따라 stride 보정.

흐름 2

Cycle 에서 Stop, Idle

이동 중 입력이 끊겨 정지로 복귀.

  1. Cycle검증State

    이동 사이클 진행 중.

  2. ↓
    NOT HasAcceleration

    입력 끊김.

  3. Stop검증State

    정지 시퀀스 (발 위치 맞추기). Distance Matching 으로 정확한 거리에서 정지.

  4. ↓

    정지 시퀀스 완료.

  5. Idle검증State

    정지 사이클.

흐름 3

PivotSources 에서 Pivot

이동 중 방향 전환. 여러 state 가 동일 조건으로 Pivot 으로 전이 가능해 alias 로 묶음.

  1. PivotSources (alias)부분Alias

    Cycle 과 Start 등 이동 중인 여러 state 의 묶음. alias membership 의 정확한 구성은 에디터 확인 필요 (부분 검증).

  2. ↓
    방향 변경 감지

    가속 벡터와 현재 이동 방향의 각도 변화.

  3. Pivot검증State

    방향 전환 동작 재생.

흐름 4

JumpSources 에서 Jump selector, Apex, Fall

점프와 낙하 진입 경로. JumpSources alias 가 ground 의 여러 state 묶음, JumpSelector conduit 이 분기.

  1. JumpSources (alias)부분Alias

    점프 가능한 ground state 묶음. membership 부분 검증.

  2. ↓
    MovementMode == Falling

    점프 입력 또는 낙하 시작.

  3. JumpSelector검증Conduit

    속도와 낙하 거리에 따라 JumpStart 또는 FallLoop 로 분기.

  4. ↓
    속도 임계값 이상
  5. JumpStart, JumpStartLoop, JumpApex검증State

    점프 상승과 정점.

  6. ↓
  7. FallLoop검증State

    낙하 루프.

흐름 5

FallLoop 에서 FallLand, Idle / Cycle

착지 후 ground 로 복귀. JumpFallInterruptSources alias 가 어디서 fall 진입 가능한지 결정.

  1. FallLoop검증State

    낙하 루프 진행.

  2. ↓
    MovementMode == Walking

    착지 감지.

  3. FallLand검증State

    착지 동작.

  4. ↓
    HasAcceleration
  5. IdleAlias 또는 CycleAlias부분Alias

    착지 후 Idle 또는 Cycle 로 복귀. alias membership 부분 검증.

주의: 본 페이지의 5 alias (PivotSources, JumpSources, JumpFallInterruptSources, IdleAlias, CycleAlias) 의 정확한 membership 은 Monolith 검증 미완 (모두 부분 검증). 에디터에서 state machine 그래프를 열어 확인 후 원장에서 본 페이지 순으로 검증 등급 승격.
