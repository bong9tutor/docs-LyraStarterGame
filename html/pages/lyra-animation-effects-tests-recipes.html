흐름 1

Anim Notify 에서 Context Effect 흐름

발자국 notify 가 surface 와 매칭되어 audio / VFX 재생까지 도달하는 인과.

  1. sequence timeline 의 notify hit검증State

    locomotion sequence 의 발 접지 frame 에서 UAnimNotify_LyraContextEffects 실행.

  2. ↓

    notify 가 EffectTag 와 bone name 을 들고 있음.

  3. ULyraContextEffectComponent 로 위임검증State

    pawn 의 effect component 가 trace 로 surface tag 결정.

  4. ↓

    DT_AnimEffectTags + CFX_DefaultSkin 매핑 lookup.

  5. audio / Niagara 재생검증State

    매칭된 entry 의 sound / VFX 가 bone 위치에서 재생.

구조

Weapon Mesh ABP 분리 구조

캐릭터 ABP 와 별도로 무기 mesh 가 자체 ABP 를 갖는다. 무기 mesh skeleton 이 캐릭터와 다르기 때문.

1ABP_Weap_Pistol

권총 slide / hammer / trigger 자체 애니메이션.

  • pistol skeleton
  • AM_Weap_Pistol_*

2ABP_Weap_Rifle

소총 bolt / magazine / trigger.

  • rifle skeleton

3ABP_Weap_Shotgun

샷건 pump / shell eject.

  • shotgun skeleton

4동기 montage 페어

캐릭터의 AM_MM_Rifle_Reload 와 weapon mesh 의 AM_Weap_Rifle_Reload 가 같은 길이로 동시 재생.

  • ability 가 두 montage 를 함께 trigger
검증

ShooterTests Animation matrix

자동 회귀 테스트가 animation 관련해서 잡는 시나리오.

  • 검증
    InputCrouchAnimationTest

    ACTOR_ANIMATION_TEST 매크로. crouch input 시 crouch sequence 가 실제로 재생되는지 확인.

  • 검증
    WeaponMeleeAnimationTest

    ACTOR_ANIMATION_TEST 매크로. melee montage 가 slot 매칭과 길이 검증.

  • 검증
    InputAnimationTest

    ACTOR_ANIMATION_NETWORK_TEST 매크로. client / server 양쪽에서 같은 animation 이 재생되는지 검증.

  • 검증
    FShooterTestsAnimationTestHelper

    FindAnimationAsset, IsAnimationPlaying 등 헬퍼 함수. 새 테스트 작성 시 이 헬퍼 사용.

레시피

새 무기 추가 레시피

기존 라이라 무기 (Pistol / Rifle / Shotgun) 을 모델로 새 무기 카테고리를 추가하는 순서.

  1. 1. weapon mesh + skeleton 임포트

    새 무기의 skeletal mesh 와 skeleton 준비. bone 이름 표준 (예: b_gun_root) 맞추기.

  2. 2. ABP_Weap_NewWeapon 생성

    기존 ABP_Weap_Rifle 복제, 새 skeleton 으로 reparent.

  3. 3. ABP_NewWeaponAnimLayers 생성

    ABP_ItemAnimLayersBase 부모. 14 인터페이스 함수 override, 새 sequence set 연결.

  4. 4. B_WeaponInstance_NewWeapon 생성

    B_WeaponInstance_Base 부모. EquippedAnimSet = ABP_NewWeaponAnimLayers, UneuippedAnimSet = ABP_UnarmedAnimLayers.

  5. 5. fire / reload montage 페어 작성

    캐릭터용 AM_MM_NewWeapon_Fire 와 weapon mesh 용 AM_Weap_NewWeapon_Fire 동시 재생되도록 길이 맞춤.

  6. 6. ability 등록

    ULyraGameplayAbility_RangedWeapon 파생 ability 가 새 무기를 인식하도록 input → ability 매핑 설정.

  7. 7. ShooterTests 추가

    ACTOR_ANIMATION_TEST 또는 ACTOR_ANIMATION_NETWORK_TEST 매크로로 새 무기의 fire / reload sequence 회귀 확인.

레시피

새 cosmetic / body style 추가 레시피

새 캐릭터 외형을 cosmetic tag 와 함께 추가하는 순서.

  1. 1. Cosmetic tag 정의

    Cosmetic.* 네임스페이스 아래 새 tag 등록 (예: Cosmetic.AnimationStyle.NewStyle).

  2. 2. invisible driving mesh 임포트

    새 body style 의 invisible skeletal mesh (SKM_NewBody_Invis) 임포트. 표준 mannequin skeleton 호환 확인.

  3. 3. visible cosmetic mesh + actor

    SKM_NewBody visible mesh, B_NewBody actor BP. ABP_Mannequin_CopyPose 적용.

  4. 4. CharacterParts 컴포넌트의 BodyMeshes entry 등록

    새 entry 의 RequiredTags = {새 cosmetic tag}, mesh = SKM_NewBody_Invis.

  5. 5. 무기 layer 의 RequiredTags 확장 (선택)

    새 cosmetic 에만 적용할 layer 가 있으면 weapon instance 의 EquippedAnimSet 배열 앞쪽에 RequiredTags 매칭 entry 추가.

  6. 6. cosmetic 적용 테스트

    pawn 의 cosmetic tag set 에 새 tag 추가 시 invisible mesh 와 layer 가 교체되는지 in-editor 확인.
