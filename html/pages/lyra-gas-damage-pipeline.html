구조

AttributeSet 2 종 (CombatSet · HealthSet)

데미지 파이프라인의 source / target attribute 분리.

1ULyraCombatSet (source)

공격자 측 attribute. instigator 의 ASC 에 있음.

  • BaseDamage (일반)
  • BaseHeal (일반)

2ULyraHealthSet (target)

피격자 측 attribute. target 의 ASC 에 있음.

  • Health, MaxHealth (일반)
  • Damage, Healing (meta, HideFromModifiers)
meta attribute: Damage 와 Healing 은 execution 이 계산해 임시로 넣는 값. PostGameplayEffectExecute 에서 Health 에 반영 후 0 으로 reset.

결정

modifier vs execution 선택

attribute 변경을 modifier 로 할지 execution 으로 할지.

  1. 1. modifier 만으로 충분한 경우

    단순 더하기 / 빼기 / 곱하기. 예: 회복 GE 가 Health 에 +50.

  2. 2. execution 필요한 경우

    여러 attribute 참조 + 동적 계산. 라이라 데미지는 BaseDamage + HitResult + Team + Distance + Material 5 입력으로 execution.

  3. 3. meta attribute 사용 이유

    execution 출력을 직접 Health 에 쓰면 modifier 가 끼어들기 어려움. meta 에 두면 PostExecute 에서 다른 정책 (immunity 등) 거쳐 Health 갱신.

  2. ↓

  4. ↓
  5. GameplayEvent_Death fire검증State
