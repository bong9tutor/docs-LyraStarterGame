구조

7 책임군 지도

라이라 애니메이션의 BP / interface 책임 분배. 7 카드로 압축. ABP_Mannequin_CopyPose 는 별도 페이지 (invisible-copy-pose) 에서 다룸.

1ABP_Mannequin_Base

state machine, slot, additive, root rotation, Control Rig 호출. pose graph 의 골격.

  • 교체 단위: 캐릭터

2ABP_ItemAnimLayersBase

sequence 변수, Distance Matching, Stride / Orientation Warping, hand IK alpha, 14 함수 구현 골격.

  • 교체 단위: 무기 카테고리

3무기별 layer ABP

Unarmed / Pistol / Rifle / Shotgun (변형 _Feminine). sequence 세트만 보유.

  • 교체 단위: 무기 인스턴스

4ABP_Weap_*

weapon mesh self-animation. 별도 skeleton 이라 캐릭터 ABP 와 분리.

  • 교체 단위: weapon mesh

5ABP_*_PostProcess

mesh 별 final-pose 보정. main ABP 출력 위에 한 번 더 평가.

  • 교체 단위: mesh

6ABP_Mannequin_Retarget

UE4 mannequin 호환. UE4 skeleton 자산을 UE5 skeleton 에 retarget.

  • 교체 단위: skeleton 호환

7ALI_ItemAnimLayers

14 함수 interface. base 와 layer 간 호출 규약. base 가 함수 이름만 알고 호출.

  • 교체 단위: 없음 (계약)

결정

새 기능 어디에 두는가

새 기능을 추가할 때 어느 책임군에 배치할지 결정 기준.

  1. 1. 새 무기 카테고리

    무기별 layer ABP + weapon instance BP 신규. base 와 ALI 는 건드리지 않음.

  2. 2. 새 sequence (기존 무기 fire / reload 등 교체)

    무기별 layer ABP 의 sequence 변수만 교체. layer 구조는 그대로.

  3. 3. 새 montage slot

    base ABP 의 AnimGraph 에 slot node 추가 + 모든 layer 가 영향 없는지 확인.

  4. 4. 새 보정 (Distance / Warping 류)

    ABP_ItemAnimLayersBase 의 ThreadSafe Update 에 새 update 함수 추가. 모든 자식 layer 가 자동 상속.

  5. 5. 새 cosmetic body style

    CharacterParts BodyMeshes entry + cosmetic actor BP. base ABP / layer 는 건드리지 않음.

  6. 6. 새 효과 (footstep / surface)

    sequence 에 notify 추가 + DT_AnimEffectTags entry. base / layer 코드는 변경 없음.

설계 의도: "교체 단위" 가 책임 분배의 핵심 기준. 자주 교체되는 단위 (무기 / cosmetic / sequence) 가 작은 BP 로 분리되고, 변하지 않는 골격 (state machine / slot) 이 base 에 남는다. 이 원칙은 새 시스템을 분석하거나 설계할 때도 같은 질문 ("이 부분은 얼마나 자주 교체되는가?") 으로 환원 가능.
