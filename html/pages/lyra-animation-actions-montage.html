챕터 브리프

이 챕터의 질문

  • montage 가 어느 slot 으로 들어가는가?
  • ability 가 melee, reload, grenade toss 같은 montage 를 어떻게 재생 요청하는가?
  • locomotion 과 상체 montage 가 충돌할 때 무엇을 확인하는가?

먼저 알아둘 것

  • Slot 노드는 base ABP 의 AnimGraph 에 박혀 있고, montage 가 자기 slot 이름과 매칭될 때 그 위치에 pose 가 끼워진다.
  • FullBody slot 은 전신, UpperBody slot 은 layered blend per bone 으로 상체에만 적용.

선행 학습

  • Base ABP pose graph: slot 5 개의 위치 표가 본 페이지 montage 의 합성 위치를 결정한다.

Ability 에서 montage 재생 흐름

GAS ability 가 montage 를 ABP slot 까지 전달하는 인과. ability 실패 시 FailureTagToAnimMontage 경로도 같은 slot 을 사용.

  1. Ability 활성화검증State

    ULyraGameplayAbility 가 input 등으로 활성화.

  2. ↓

    PlayMontageAndWait task 또는 ability 내부 PlayMontage 호출.

  3. PlayMontage on Owner SkeletalMesh검증State

    target montage 의 첫 slot 이름이 ABP slot 과 매칭되어 평가.

  4. ↓

    ability 실패 분기: FailureTagToAnimMontage 매핑이 있으면 failure montage 재생.

  5. ABP AnimGraph 에서 slot 합성검증State

    cached pose 위에 montage pose 가 slot 위치에 끼워짐. blend weight 는 slot blend in / out 설정.

  6. ↓
  7. 출력 pose 에 반영검증State

    Control Rig 와 Inertialization 후 화면에 표시.

검증

locomotion + montage 충돌 점검

montage 가 의도와 다르게 보일 때 확인할 항목.

  • 검증
    slot 이름 일치

    montage 첫 segment 의 slot 이름이 base ABP 의 slot 노드 이름과 정확히 일치.

  • 검증
    FullBody 와 UpperBody 동시 재생

    UpperBody slot 은 layered blend per bone 이라 FullBody 의 하체와 자연스럽게 합성. FullBody montage 가 동시 재생되면 UpperBody 가 hidden 될 수 있음.

  • 검증
    blend weight 0

    slot blend in / out 시간이 montage 보다 길면 montage 가 보이기 전에 끝남.

  • 부분
    WeaponMeleeAnimationTest 통과 여부

    ShooterTests 의 WeaponMeleeAnimationTest 가 melee montage 의 slot 매칭과 길이 회귀를 잡음. 구체 테스트 코드 위치는 추가 확인 필요.
