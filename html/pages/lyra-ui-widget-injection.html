결정

EUIExtensionPointMatch 매칭 규칙

extension point widget 이 어떤 widget 을 받을지 결정하는 규칙.

  1. 1. ExactMatch

    SlotID 가 정확히 일치하는 widget 만 받음. 가장 엄격.

  2. 2. PartialMatch

    SlotID 의 자식 태그도 매칭 (예: HUD.Slot.Equipment point 가 HUD.Slot.Equipment.Primary widget 도 받음).

  3. 3. AllowedDataClasses contract

    extension point 가 받을 데이터 클래스를 제한. FUIExtensionPoint::DoesExtensionPassContract 검사.

  4. 4. 한 slot 에 widget 2 개

    둘 다 등록되어 priority 순으로 표시. priority -1 동등 시 등록 순서. 예: HUD.Slot.RightSideTouchInputs 에 joystick + fire button.
