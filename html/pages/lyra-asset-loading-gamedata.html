레시피

새 전역 데이터 추가 레시피

예: DefaultCameraSettings 같은 전역 자산 추가.

  1. 1. 새 DataAsset 클래스

    UPrimaryDataAsset 파생 UDefaultCameraSettings. 멤버 정의.

  2. 2. AssetManager 에 path + getter 추가

    UPROPERTY(Config) TSoftObjectPtr<UDefaultCameraSettings> DefaultCameraSettingsPath; + const UDefaultCameraSettings& GetDefaultCameraSettings();.

  3. 3. DefaultGame.ini 에 경로 등록

    [/Script/LyraGame.LyraAssetManager] 절에 DefaultCameraSettingsPath=/Game/System/DefaultCameraSettings.DefaultCameraSettings.

  4. 4. 자산 생성

    에디터에서 Content/System/DefaultCameraSettings.uasset 생성.

  5. 5. (선택) StartupJob 등록

    첫 사용 시 hitch 가 싫으면 STARTUP_JOB 으로 부팅 시 preload.
