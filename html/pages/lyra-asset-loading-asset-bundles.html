흐름 1

ChangeBundleStateForPrimaryAssets 흐름

runtime 에 bundle 단위 비동기 로드를 요청하면 메타 분류된 자산이 일괄 로드.

  1. StartExperienceLoad 가 BundlesToLoad 결정검증State

    NetMode 별 분기: server 이면 [Server], listen 이면 [Client, Server], client 이면 [Client].

  2. ↓
  3. ChangeBundleStateForPrimaryAssets 호출검증State

    AssetManager 가 BundleAssetList 와 BundlesToLoad 로 비동기 로드 시작.

  4. ↓
  5. 메타 자동 수집 + override 추가 수집검증State

    meta=(AssetBundles) 자동 수집 외, AddAdditionalAssetBundleData override 가 커스텀 자산 추가.

  6. ↓
  7. OnExperienceLoadComplete검증State

    모든 자산 로드 완료 시 콜백. 다음 state 진행.

결정

Client / Server 분류 규칙

자산을 어느 bundle 에 둘지 결정 기준.

  1. 1. UI 자산

    Client 만. dedicated server 는 렌더 안 함, 메모리 절약.

  2. 2. 게임플레이 자산

    Client,Server 양쪽. ASC, AbilitySet, GE 등 server 도 실행 필요.

  3. 3. Input mapping

    Client 만. server 는 입력 처리 안 함.

  4. 4. mesh / animation

    일반적으로 Client,Server. server 도 hit detection 위해 mesh 필요.

검증

LAS_ShooterGame_StandardHUD 검증

대표 ActionSet 의 AssetBundleData 자동 수집 검증.

  • 검증
    Layout 1 widget 수집

    W_ShooterHUDLayout 이 Client bundle 에 등록.

  • 검증
    Widgets 11 widget 수집

    QuickBar / Reticle / ... 11 widget 이 Client bundle. override AddAdditionalAssetBundleData 가 자동 수집 보완.

  • 검증
    B_LyraDefaultExperience AssetBundleData = 1

    Experience CDO 가 AssetBundle 1 entry. (검증 원장)

참조

FLyraBundles::Equipped 의미

라이라가 추가로 정의한 bundle 이름. 무기 / 장비의 conditional 로드.

  • FLyraBundles::Equipped: 무기 / 장비가 실제로 장착되었을 때만 로드되는 bundle.
  • 장비 instance 가 ChangeBundleStateForPrimaryAssets(..., [Equipped]) 호출.
  • 장착 해제 시 unload.
