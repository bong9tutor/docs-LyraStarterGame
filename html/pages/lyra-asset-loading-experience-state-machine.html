흐름 1

7 단계 state 진행 흐름

Experience 선택부터 LoadingScreen 종료까지의 state 진행.

  1. Unloaded검증State

    초기 state. SetCurrentExperience(FPrimaryAssetId) 호출 대기.

  2. ↓

    SetCurrentExperience 호출, AssetPath.TryLoad() 동기.

  3. LoadingGameFeatures검증State

    Experience 의 GameFeaturesToEnable[] 일괄 활성화 시작. NumGameFeaturePluginsLoading 증가.

  4. ↓
  5. LoadingChaosTestingDelay검증State

    CVar 로 조정 가능한 chaos testing delay. 비동기 timing 검증용.

  6. ↓
  7. ExecutingActions검증State

    Experience 의 Actions[] + ActionSets 의 Actions[] 일괄 실행 (AddWidgets / AddComponents / ...).

  8. ↓
  9. Loaded검증State

    모든 단계 완료. OnExperienceLoaded_* delegate broadcast.

  10. ↓
  11. Deactivating부분State

    map 전환 시 Experience 해제 시작. 구체 deactivation 순서는 부분 검증.

  12. ↓
  13. Deactivated부분State

    해제 완료, 다음 Experience 로드 대기.

결정

Priority 3 단 콜백

CallOrRegister_OnExperienceLoaded_* 3 종 콜백의 용도 분리.

  1. 1. HighPriority

    먼저 broadcast. 다른 시스템이 의존하는 setup (예: GameState 초기화).

  2. 2. Normal

    중간 broadcast. 일반 등록 콜백.

  3. 3. LowPriority

    가장 늦게 broadcast. 다른 모든 system 이 준비된 후 실행 (예: UI 표시).

주의: Priority 는 실행 순서 보장이지 비동기 분리 아님. 모두 같은 frame 에 순차 호출.
