구조

런타임 책임 지도

라이라 애니메이션을 학습용 책임 단위로 묶은 지도. 이 구조를 먼저 잡으면 뒤 페이지의 상세 흐름을 읽기 쉽다.

1상태 입력

ULyraAnimInstance 가 GAS tag 를 ABP 변수로 미러링하고 GroundDistance 를 갱신한다.

  • GameplayTagPropertyMap
  • Movement mode · Crouch
  • Ground tracing

2Base character ABP

ABP_Mannequin_Base: 이동 상태 머신, cached pose, montage slot, 상하체 분리, root yaw, Control Rig, linked layer 호출 위치를 갖는다.

  • LocomotionSM
  • slot node 5 종
  • LinkedAnimLayer node 4 종

3Linked item layers

base 가 상태와 호출 위치를 정하면 무기별 layer 가 실제 full-body state 와 aiming, additive, skeletal-control 구현을 제공한다.

  • ALI_ItemAnimLayers 14 인터페이스 함수
  • ABP_ItemAnimLayersBase
  • 무기별 child layer

4선택 규칙

ULyraWeaponInstance 와 cosmetic tag 가 equipped / unequipped layer 와 Manny / Quinn 계열 mesh 를 고른다.

  • EquippedAnimSet · UnequippedAnimSet
  • Cosmetic.AnimationStyle.Feminine

5효과·검증

Anim Notify 가 Context Effect 로 분기, ShooterTests 자동화, 보정 스택 (Distance Matching, Warping, Control Rig, Post Process, Retarget).

  • AnimNotify_LyraContextEffects
  • ShooterTests Animation matrix
흐름 1

캐릭터가 화면에 나타나기까지의 흐름

Pawn 이 spawn 되고 ASC 가 초기화되며 AnimInstance 가 connect 된 뒤 첫 frame 의 pose 가 만들어지기까지의 인과.

  1. Pawn spawn + ASC init검증State

    ULyraAbilitySystemComponent::InitAbilityActorInfo 가 ASC 와 Avatar 를 연결하면서 AnimInstance 의 GameplayTag 매핑이 활성화된다.

  2. ↓

    ASC 가 Pawn 의 AnimInstance 를 찾고 InitializeWithAbilitySystem 으로 tag 미러를 시작.

  3. AnimInstance NativeInitialize검증State

    ULyraAnimInstance 가 FGameplayTagBlueprintPropertyMap 으로 tag 변수를 ABP 와 묶고 character / movement 컴포넌트를 캐싱.

  4. ↓

    매 frame 에 Game Thread 가 BlueprintThreadSafeUpdateAnimation 을 병렬로 호출.

  5. ThreadSafe Update 와 AnimGraph 평가검증State

    ABP 변수 갱신 (10 단계 Update*Data) 후 LocomotionSM, linked layer 호출, slot 합성, Control Rig 를 거쳐 최종 pose 산출.

  6. ↓

    결과 pose 가 SkeletalMesh 로 출력되고 cosmetic mesh 가 Copy Pose 로 따라온다.

  7. 최종 pose 출력검증State

    Post Process ABP (ABP_Manny_PostProcess 또는 ABP_Quinn_PostProcess) 가 추가 보정 후 화면에 표시.

참조

시스템 페이지 경로

위 책임 지도와 흐름을 깊이 학습하는 페이지들. 좌측 사이드바와 페이지 끝 페이저에서도 동일 순서로 이동.

  • runtime-state: ASC tag 에서 ABP 변수 미러링과 ThreadSafe 갱신 구조.
  • base-abp: Base ABP pose graph, cached pose, slot, linked layer 호출 지점.
  • locomotion-sm: Idle, Start, Cycle, Stop, Pivot, Jump / Fall 5 흐름.
  • linked-layers: ALI 14 함수 인터페이스와 무기별 layer 차이.
  • selection-rules: SelectBestLayer, body style rule, EquippedAnimSet.
  • actions-montage: Ability 에서 AnimMontage, ABP slot 까지의 인과.
  • aiming-additives: Aim offset, ADS, additive 합성 frame pipeline.
  • warping-ik: Distance Matching, Warping, IK, Post Process, Retarget 보정 스택.
  • effects-tests-recipes: Notify 에서 Context Effect 와 ShooterTests, 확장 레시피.
  • animbp-ali-tradeoffs: 설계 페이지. 7 책임군 배치의 비용과 이득.
  • invisible-copy-pose: 설계 페이지. 보이지 않는 driving mesh 와 Copy Pose 아키텍처.
