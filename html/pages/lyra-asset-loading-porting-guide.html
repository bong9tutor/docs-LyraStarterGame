검증

포팅 전 사전 경고 4 가지

자주 빠지는 함정. 포팅 시작 전 반드시 확인.

  • 검증
    ini 절 위치

    핵심 4 절 (LyraAssetManager / AssetManagerSettings / GameFeaturesSubsystemSettings / CommonLoadingScreenSettings) 은 DefaultGame.ini 에. AssetManagerClassName 만 DefaultEngine.ini 에.

  • 검증
    Experience definition 자체는 동기 로드

    SetCurrentExperience(FPrimaryAssetId) 의 AssetPath.TryLoad() 가 blocking. 소스 주석 //@TODO: Async load the experience definition itself.

  • 검증
    DefaultGameData 의 soft class 는 즉시 로드 보장 없음

    TSoftClassPtr<UGameplayEffect> 이라 GameData 자산 로드 와 GE 클래스 로드 가 다름. 첫 호출 hitch 가능.

  • 검증
    AssetBundleData 수집은 2 메커니즘

    자동 (meta=(AssetBundles)) + 수동 (AddAdditionalAssetBundleData override). 커스텀 GameFeatureAction 의 배열 자산은 override 필요.

비교

포팅 옵션 A / B / C

작업량과 적합한 경우 비교.

옵션가져갈 부분작업 시간적합한 경우
A (최소)AssetManager 파생 + Primary Asset Type 등록1 시간전역 데이터 자산 1 개만 필요
B (중간)A + GameData 패턴 + StartupJob 큐4 시간부팅 시 비동기 로드 + 진행률 보고 필요
C (전체)B + Experience 시스템 + GameFeature 통합 + Loading Screen1-2 일라이라 풍의 데이터 주도 게임 모드 시스템 필요
레시피

옵션 A 레시피 (1 시간)

최소 포팅. AssetManager 파생 + Primary Asset Type 등록.

  1. A.1 Build.cs 의존성

    PublicDependencyModuleNames 에 "GameplayTags" 확인 (대부분 기본 포함).

  2. A.2 AssetManager 파생 클래스

    UAssetManager 파생 U{Prefix}AssetManager. UCLASS(Config = Game). StartInitialLoading override.

  3. A.3 DefaultEngine.ini 등록

    [/Script/Engine.Engine] 절에 AssetManagerClassName=/Script/{프로젝트}.{Prefix}AssetManager.

  4. A.4 (선택) Primary Asset Type 1 개 등록

    DefaultGame.ini 의 [/Script/Engine.AssetManagerSettings] 절에 +PrimaryAssetTypesToScan=(...).

레시피

옵션 B 레시피 (4 시간)

A + 전역 데이터 자산 + StartupJob + 진행률.

  1. B.1 StartupJob 패턴 복사

    LyraAssetManagerStartupJob.h/.cpp 그대로 복사, 클래스명 prefix 교체.

  2. B.2 AssetManager 에 startup job 추가

    STARTUP_JOB_WEIGHTED 매크로 정의 + StartInitialLoading 안에 등록 + DoAllStartupJobs() 호출.

  3. B.3 GameData 전역 자산 패턴

    UPrimaryDataAsset 파생 + GetOrLoadTypedGameData<T> template + LoadGameDataOfClass 헬퍼.

  4. B.4 DefaultGame.ini 에 GameData 경로

    [/Script/{프로젝트}.{Prefix}AssetManager] 절에 MyGameDataPath=....

  5. B.5 자산 생성 + 검증

    에디터에서 자산 생성. 부팅 로그에 Startup job "GetMyGameData()" took N.NN seconds 확인.

레시피

옵션 C 레시피 (1-2 일)

B + Experience + GameFeature + Loading Screen 통합.

  1. C.1 ExperienceManagerComponent 골격 복사

    7 단계 state machine 그대로. NetMode 분기와 NumGameFeaturePluginsLoading 카운트다운 패턴.

  2. C.2 ExperienceDefinition + ActionSet 자산 정의

    UPrimaryDataAsset 파생 + Actions[] + GameFeaturesToEnable[].

  3. C.3 AssetBundleData 메타 부여

    모든 soft pointer 자산에 meta=(AssetBundles="Client,Server") 또는 "Client".

  4. C.4 GameFeature plugin 등록

    DefaultGame.ini 의 [/Script/GameFeatures.GameFeaturesSubsystemSettings] 절에 plugin 경로 등록.

  5. C.5 Loading Screen 통합

    CommonLoadingScreen plugin 활성화 + [/Script/CommonLoadingScreen.CommonLoadingScreenSettings] 의 host widget 경로 등록.

  6. C.6 AsyncAction_ExperienceReady BP 노드

    BP 가 Experience 완료를 기다리도록 UBlueprintAsyncActionBase 파생 4 step 패턴 복사.
