이 챕터의 질문

  • AnimGraph 의 노드 구성은 어떻게 되는가?
  • cached pose 2 개는 왜 필요한가?
  • slot 5 개는 무엇이 어디에 합성되는가?

  • AnimGraph 는 위에서 아래로 pose 가 흐른다 (state machine, cached, split, slot, control rig, output).
  • Cached pose 는 같은 pose 를 여러 곳에서 재사용할 때 평가 비용을 1 회로 줄인다.

구조

Pose graph 5 계층 스택

최종 pose 가 통과하는 큰 블록. 위쪽이 입력 (state machine 으로 만든 locomotion pose), 아래쪽이 출력 (mesh 로 보내는 pose).

1LocomotionSM

이동 상태 머신으로 locomotion pose 생성.

  • Idle · Start · Cycle · Stop · Pivot · Jump / Fall

2Cached pose: Locomotion

locomotion pose 를 캐시해 여러 곳에서 재사용.

  • cached pose 첫 번째

3Cached pose: UpperbodyLowerbodySplit

Layered Blend Per Bone 으로 상하체 분리한 결과 캐시.

  • cached pose 두 번째

4Slot 합성과 Linked layers

slot 5 종 (montage 재생 지점) 과 linked layer 4 종 (aiming, additive, skel control, 손 pose) 가 cached pose 위에 합성.

  • FullBody · UpperBody · Additive · LeftHandPose

5Rotate Root Bone, Control Rig, Output

최종 보정. turn in place 의 root yaw 회전, Control Rig 절차적 보정, Inertialization, output pose.

  • Rotate Root Bone
  • Control Rig node
  • Inertialization
참조

Slot 5 개와 LinkedAnimLayer 4 개

Base ABP 가 노출하는 slot 과 호출하는 linked layer 함수의 위치. montage 와 layer 가 어디로 들어가는지 학습 시 이 표가 단일 출처.

이름종류역할
FullBodyslot전신 montage 재생 위치 (jump, death, 발 동작 등).
UpperBodyslot상체 전용 montage 재생 위치 (재장전, grenade toss 등).
AdditiveHitReactslot피격 반응 additive 재생.
FullBodyAdditivePreAimslotaim offset 적용 전 전신 additive.
UpperBodyAdditiveslot상체 전용 additive.
FullBody_AimingLinkedAnimLayer무기별 layer 의 aim offset, ADS 합성.
FullBodyAdditivesLinkedAnimLayer무기별 layer 의 추가 additive 합성.
FullBody_SkeletalControlsLinkedAnimLayer무기별 layer 의 skeletal control (사격 자세, 손가락).
LeftHandPose_OverrideStateLinkedAnimLayer왼손 grip pose override.
흐름 1

한 frame pose 가 만들어지는 흐름

state machine 결과부터 출력 pose 까지의 평가 순서. 각 단계가 위 스택의 한 계층에 대응.

  1. LocomotionSM 평가검증State

    현재 state (Idle, Cycle, Jump 등) 가 자기 pose 출력.

  2. ↓

    cached pose 첫 번째 (Locomotion) 에 저장.

  3. Layered Blend Per Bone검증State

    상하체 본 가중치로 분리. cached pose 두 번째 (UpperbodyLowerbodySplit) 저장.

  4. ↓

    slot 과 linked layer 합성.

  5. Slot 과 LinkedAnimLayer 합성검증State

    위 참조 표의 slot 5 와 linked layer 4 가 cached pose 위에 순서대로 얹힘.

  6. ↓

    root yaw 와 IK 보정.

  7. Rotate Root Bone, Control Rig, Inertialization 후 Output검증State

    turn in place 회전 적용, Control Rig 로 IK 및 보정, 마지막 Inertialization 으로 전이 부드럽게.
