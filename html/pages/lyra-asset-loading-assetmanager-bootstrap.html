참조

ini 설정 3 종

라이라 AssetManager 의 ini 설정. AssetManagerClassName 만 DefaultEngine.ini 에, 나머지 2 종은 DefaultGame.ini 에.

ini 파일절키 와 의미
DefaultEngine.ini[/Script/Engine.Engine]AssetManagerClassName=/Script/LyraGame.LyraAssetManager: 엔진이 사용할 AssetManager 클래스 결정
DefaultGame.ini[/Script/LyraGame.LyraAssetManager]LyraGameDataPath=/Game/System/DefaultGameData.DefaultGameData: GameData 자산 경로
DefaultGame.ini[/Script/LyraGame.LyraAssetManager]DefaultPawnData=/Game/Characters/Heroes/Mannequin/PawnData.PawnData: 기본 PawnData
주의: UPROPERTY(Config) + UCLASS(Config = Game) 패턴이라 멤버는 DefaultGame.ini 에서 읽힘. DefaultEngine.ini 에 두면 무시.
흐름 1

AssetManager 부팅 흐름

엔진이 ini 설정을 읽고 라이라 AssetManager 를 생성, StartInitialLoading 호출까지.

  1. 엔진 부팅 초기검증State

    DefaultEngine.ini 의 AssetManagerClassName 읽음.

  2. ↓
  3. ULyraAssetManager 생성검증State

    GEngine->AssetManager 에 인스턴스 저장. UPROPERTY(Config) 멤버가 DefaultGame.ini 에서 자동 채워짐.

  4. ↓
  5. StartInitialLoading 호출검증State

    엔진이 부팅 hook 호출. 라이라가 override 해서 StartupJob 큐 등록 + 실행.

  6. ↓
  7. GameInstance 진행검증State

    초기 로드 완료 후 일반 게임 부팅 진행.

결정

StartInitialLoading vs PreBeginPIE

부팅 hook 의 두 override 지점. 어떤 경우에 어떤 것을 쓰는가.

  1. 1. StartInitialLoading

    실제 게임 부팅 (cooked build) 과 PIE 모두에서 호출. 라이라는 이 hook 만 override.

  2. 2. PreBeginPIE

    에디터 PIE 진입 직전에만 호출. PIE 전용 reset 이 필요할 때.

  3. 3. 라이라 선택

    PIE / 실 빌드 일치 위해 StartInitialLoading 만 사용. PIE 분기는 GIsEditor 로 함수 내부에서 처리.
