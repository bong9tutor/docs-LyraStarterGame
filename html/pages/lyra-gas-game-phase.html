이 챕터의 질문

  • 왜 페이즈를 어빌리티 (ULyraGamePhaseAbility) 로 표현하는가?
  • GameState 의 ASC 가 페이즈 어빌리티의 owner / avatar 가 되는 이유는?
  • 페이즈 계층 (Game.Playing + Game.Playing.SuddenDeath) 의 부모-자식 관계는?

흐름 1

페이즈 전이 흐름

Phase_Warmup 에서 Phase_Playing, Phase_PostGame.

  1. StartPhase(Phase_Warmup)검증State

    GameMode 가 매치 시작 시 호출. Warmup ability 가 GameState ASC 에 grant + activate.

  2. ↓
  3. OnBeginPhase 콜백검증State

    WhenPhaseStartsOrIsActive(Phase_Warmup, ...) 구독자 호출. 예: GE_PregameLobby 적용.

  4. ↓

    Warmup 타이머 종료.

  5. StartPhase(Phase_Playing)검증State

    Playing ability 활성. OnBeginPhase 가 형제 페이즈 (Warmup) 자동 취소.

  6. ↓
  7. 매치 종료 후 StartPhase(Phase_PostGame)검증State

    PostGame ability 활성. 점수 표시 등.

결정

EPhaseTagMatchType (Exact vs Partial)

페이즈 tag 매칭 규칙.

  1. 1. ExactMatch

    정확히 같은 tag 만 매칭. 예: Game.Playing 구독 시 Game.Playing.SuddenDeath 활성에는 반응 안 함.

  2. 2. PartialMatch

    자식 tag 도 매칭. Game.Playing 구독 시 Game.Playing.SuddenDeath 활성에도 콜백 실행.

  3. 3. 형제 페이즈 자동 취소

    OnBeginPhase 가 새 페이즈와 같은 부모를 가진 활성 페이즈 (형제) 만 취소. 부모는 유지.
