검증

미구현 사실 확인

현재 시점 UE 5.7 에서 HiddenByTags 의 런타임 listening 이 동작하지 않음.

  • 검증
    코드 주석에 UE-142237 명시

    ULyraTaggedWidget 의 NativeConstruct / NativeDestruct 에 @TODO UE-142237 주석.

  • 검증
    bHasHiddenTags = false 하드코딩

    현재 구현이 항상 false 반환. 런타임 tag 변경 listening 미작동.

  • 검증
    SetVisibility 가 호출되지 않음

    tag 변경에 따른 visibility 토글 경로가 끊겨 있음.

중요: ULyraTaggedWidget 의 HiddenByTags 필드를 설정해도 런타임에 무시. UI 가 의도와 다르게 항상 표시될 수 있음.

결정

가시성 게이팅이 필요할 때 권장 방식

HiddenByTags 가 미작동인 현 시점 권장 대안.

  1. 1. Platform trait 기반

    UCommonUIVisibilitySubsystem 사용. 정적 (런타임 미변경) 가시성에 적합.

  2. 2. Viewmodel binding

    위젯 BP 의 binding 으로 viewmodel property 변화에 따라 visibility 갱신. 동적 변화에 적합.

  3. 3. GAS event listening

    위젯이 ASC 의 tag change delegate 를 직접 구독해 SetVisibility 호출. ASC tag 변화 추적.

  4. 4. Widget BP custom binding

    UMG 의 visibility binding 함수에서 직접 조건 평가. 가장 유연하지만 BP 컴파일 비용.
