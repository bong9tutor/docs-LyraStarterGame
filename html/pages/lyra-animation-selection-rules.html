결정

SelectBestLayer 우선순위 규칙

FLyraAnimLayerSelectionSet 은 Layers 배열을 순서대로 평가, 첫 매칭 반환. 매칭 규칙은 layer entry 의 RequiredTags 가 입력 tag set 의 부분집합이면 매칭.

  1. 1. RequiredTags 가 비어 있는 entry

    모든 cosmetic tag set 에 매칭. fallback 으로 사용 시 배열 마지막에 둠.

  2. 2. RequiredTags 가 입력 tag 의 부분집합

    예: entry RequiredTags = {Cosmetic.AnimationStyle.Feminine}, 입력 = {Cosmetic.AnimationStyle.Feminine, Cosmetic.Body.Default} 이면 매칭.

  3. 3. 매칭이 없으면 nullptr

    nullptr 반환 시 base ABP 는 UneuippedAnimSet default 또는 기존 layer 유지 (코드 경로별로 다름).

참조

weapon instance CDO 의 두 set

기본 무기 BP 들의 EquippedAnimSet 과 UneuippedAnimSet 값. 학습 시 이 표가 단일 출처. 실제 BP 의 CDO 에서 확인.

weapon instanceEquippedAnimSet (주요 entry)UneuippedAnimSet (주요 entry)

결정

body style mesh 선택 규칙

ULyraPawnComponent_CharacterParts::BroadcastChanged 가 cosmetic tag 변경 시 BodyMeshes.SelectBestBodyStyle(MergedTags) 로 invisible driving mesh 를 결정.

  1. 1. SelectBestBodyStyle 호출

    FLyraAnimBodyStyleSelectionSet 도 layer selection 과 같은 RequiredTags 부분집합 규칙. 첫 매칭 mesh entry 반환.

  2. 2. 매칭된 entry 의 mesh + ForcedPhysicsAsset 적용

    SetSkeletalMesh(InvisibleMesh, true) 로 driving mesh 교체. ForcedPhysicsAsset 이 있으면 함께 적용.

  3. 3. delegate broadcast

    변경 알림. cosmetic actor (B_Manny, B_Quinn) 의 visible mesh 가 ABP_Mannequin_CopyPose 로 pose 를 따라옴.

관련: 왜 driving mesh 와 visible cosmetic mesh 가 분리됐는지는 invisible-copy-pose 페이지 참조.
