Activatable widget lifecycle

위젯이 활성화되면서 input config 가 적용되고 비활성화 시 복원되는 흐름.

  1. 위젯 활성화 요청검증State

    layer 또는 stack 에 push 또는 ActivateWidget() 호출.

  2. ↓
  3. NativeOnActivated검증State

    UCommonActivatableWidget::NativeOnActivated 호출, BP_OnActivated 이벤트 발생.

  4. ↓

    ULyraActivatableWidget::GetDesiredInputConfig 호출.

  5. FUIInputConfig 적용검증State

    ELyraWidgetInputMode 가 FUIInputConfig 로 변환되어 input mode, mouse capture, cursor 결정.

  6. ↓
  7. NativeOnDeactivated검증State

    위젯 종료 시 input config 복원, BP_OnDeactivated 이벤트.

결정

desired focus target 강제 검증

라이라는 컴파일 시점에 BP_GetDesiredFocusTarget 미구현 시 경고를 표시.

  1. 1. ValidateCompiledWidgetTree 검사

    ULyraActivatableWidget::ValidateCompiledWidgetTree 가 BP_GetDesiredFocusTarget override 여부 확인.

  2. 2. 미구현 시 컴파일 경고

    BP 컴파일 시 경고 표시. 게임패드 navigation 의 첫 focus 가 정해지지 않아 입력 도달이 끊길 수 있음.

  3. 3. modal 위젯의 경우 필수

    bIsModal == true 위젯은 다른 위젯으로 focus 가 빠질 수 없으므로 desired focus target 이 반드시 필요.
