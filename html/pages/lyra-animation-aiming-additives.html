흐름 1

AimPitch / AimYaw 가 pose 까지 흐르는 과정

controller 회전 입력이 aim offset 으로 변환되어 cached pose 위에 얹히는 인과.

  1. Controller pitch / yaw검증State

    player input 또는 AI controller 가 회전 입력을 만듦.

  2. ↓

    AnimInstance NativeUpdate 가 AimPitch, AimYaw 갱신.

  3. linked layer 의 FullBody_Aiming 호출검증State

    base ABP 가 무기별 layer 의 FullBody_Aiming 을 호출, layer 내부 aim offset BlendSpace 평가.

  4. ↓

    AimOffsetBlendWeight 로 합성 가중치 결정.

  5. cached pose 위에 aim offset 합성검증State

    locomotion cached pose 위에 aim offset 이 weight 만큼 합성.

  6. ↓
  7. FullBodyAdditives, FullBody_SkeletalControls 적용검증State

    추가 additive (사격 반동 등) 와 skeletal control (손가락 trigger pose) 합성.

결정

ADS / hipfire / raise 분기 규칙

aiming state 가 어떤 sample 세트와 weight 를 고르는지.

  1. 1. ADS 상태

    IsADS == true 이면 무기 layer 가 IdleAimOffset sample 사용 (조준 자세). AimOffsetBlendWeight 도 1 에 가까움.

  2. 2. hipfire 상태

    IsADS == false, 사격 후 짧은 시간 이면 RelaxedAimOffset sample + raise 가중치. 사격 직후 무기가 잠시 들렸다 내려옴.

  3. 3. raise 종료 조건

    TimeSinceFiredWeapon 이 RaiseWeaponAfterFiringDuration 초과 시 raise weight 0 으로 감쇠. crouch 시 RaiseWeaponAfterFiringWhenCrouched 가 false 면 raise 적용 안 함.
